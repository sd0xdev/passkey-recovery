# Home atlas — original assets and their source

Every visual on the Home page is original to this repository (author: sd0x, license: Apache-2.0, like the rest
of the code). The atlas adds no third-party image, icon set, font or case material; the only third-party asset it
uses is the product's already bundled, credited fonts (below). Plan: `docs/features/open-source-recovery/6-recovery-atlas.md` §4.

| Asset | Form | Source of truth |
|---|---|---|
| Hero plate, wide and tall compositions (station, funds, structure, registration marks, callouts, legend) | Hand-written SVG in React | `Plate.tsx`, coordinates in `geometry.ts` |
| Depth lines on every plate | Generated SVG paths, deterministic | `ring()` in `geometry.ts` |
| Three static plates (I, II, III) | The same plate in three states | `Plate.tsx` with `TALL` |
| Boundary map (night edition) | HTML regions with CSS borders | `Boundary.tsx`, `atlas.css` |
| Demo stills ×4 (`../assets/demo-*.webp`) | WebP screenshots of the real tool | Regenerated by `scripts/design/capture-demo.mjs` from `test/e2e/flow.spec.ts` on the synthetic e2e testchain (`test/support/e2e-servers.ts`): synthetic accounts and gas wallet, no real address, no 1Password link, no pairing code, no real receipt |

The shipped stills are pinned by SHA-256. A new capture is never byte-identical (fee amounts and the validity
countdown differ per run), so replacing them means: run `capture-demo.mjs` (it rejects any still that is not a
1280×736 PNG), look at all four, then update this table.
